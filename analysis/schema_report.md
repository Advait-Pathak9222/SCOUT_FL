## 2. Per-unit artifact schema

One JSON file per `(tag, point, method, seed)` unit (`utils/runstore.py`), rewritten
atomically after every round (resumable). Top-level keys:

```
meta       : {method, seed, point, tag, K, budget, rounds, dataset, model}
complete   : bool          # analysis skips incomplete units
rounds     : [ per-round row, ... ]
objectives : {acc, best_acc, logdet, crb, agg_mse, jain, energy, round_s,
              logdet_final, crb_final} | null
```

Per-round row keys (the ones this program consumes):

```
round, test_acc, test_loss, train_loss,
selected            # <-- list[int] of selected client indices (LOGGED every round) ✓
sensing_logdet, crb, agg_mse, grad_sq, energy, latency,
learning_util, coverage_util, fairness_util, dual_mse, mse_violation,
select_time, round_time,
jedi_* (9 diagnostics), vis_* (5 diagnostics)
```

**`objectives` aggregation convention (critical, design §0.3):** `acc` is FINAL-round
accuracy; `logdet`/`crb`/`agg_mse`/`energy` are ROUND-MEANS; `logdet_final`/`crb_final`
are the final-round sensing values. The design mandates **final-round CRB primary** →
new analysis reads `crb_final` for the primary sensing convention and reports round-mean
`crb` as secondary.

## 5. What the design needs that the artifacts LACK — and the chosen workaround

| Design dependency | Logged? | Workaround (implemented) |
|---|---|---|
| Per-round **selected sets** (leakage accountant, tracker re-score) | **Yes** ✓ | Read directly from `rounds[t].selected`. |
| **Client positions** | No | `scout_fl/infra/replay.py` reconstructs them deterministically from `(config, seed)` — the pipeline is fully seeded. **Verified:** reconstructed round-0 sensing log-det matches the logged value to <5e-5 across `aircomp_mse_min/asaad/collabsensefed/comm_only` (see `tests/test_infra_replay.py`). |
| **Target positions / trajectories** | No | Reconstructed via `replay.reconstruct(...).targets`; ground-truth mobility trajectories are generated fresh by `infra/mobility.CVMobility` (design §0.2.3) for all NEW runs and logged per unit. |
| **Per-client channel gain / uplink SNR** | Not per-client (only aggregate `agg_mse`) | `replay.reconstruct` reproduces `g` and `snr_up = P·g/σ²` bit-for-bit by replaying the exact RNG draw order of `run_seed`. |
| **Posterior covariance P_{t,m} / tracking RMSE** | No (campaign was stationary, myopic) | Computed by re-scoring: replay geometry → feed logged selections through `infra/tracker.InformationKalmanTracker`. E-T2 tracker-sanity runs this on existing artifacts. |
| **Client-position leakage FIM** | No | New metric: `infra/leakage.LeakageAccountant`, fed by replay. |

### E-C4 decision (design §2.6 permits either path)
Because replay reproduces geometry+channel exactly (verified ≤5e-5), **E-C4 re-scores the
existing 32-method × 5-seed CIFAR-10 artifacts directly** (near-zero GPU) rather than
re-running the top-9. The re-run-top-9 path remains available in `run_all.sh` as
`ec4_rerun` if an artifact set is missing (falls back per §2.6). This is strictly better
than the design's fallback: all 32 methods are covered, not 9.

### E-T2 / static-frontier tracker re-scoring
Same mechanism: the 32-method static frontier is re-scored through the tracker to obtain
`time_avg_trP` and terminal CRB **without re-running FL** (design §1.6: "re-scored with
tracker where trajectories permit"). Stationary (σ_p=0) uses the reconstructed static
targets; σ_p>0 comparisons require fresh runs (built as TEMPO train units).

## 6. Determinism contract

`utils/seed.seed_everything(seed)` seeds Python/NumPy/torch and returns the Generator;
`build_scenario`, `comm_channel_gains`, and `compute_het` draw from it in a fixed order.
Every new artifact re-logs its seed in `meta`. Replay depends on this order being stable —
`tests/test_infra_replay.py` guards it against regressions.
